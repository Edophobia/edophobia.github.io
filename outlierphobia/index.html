Account

YouTube API key

Outlierphobia reads public YouTube data with your own free key. It's saved in your account, so you only paste it once.

  1. Open YouTube Data API v3 and press Enable.
  2. Go to Credentials → Create credentials → API key.
  3. Edit the key: under API restrictions, allow only YouTube Data API v3.
